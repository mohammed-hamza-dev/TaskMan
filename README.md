# ✅ TaskMan

TaskMan is a React-based task management application for creating, organizing, and tracking everyday tasks.

## 🚀 Live Demo

**[Open TaskMan](https://mohammed-hamza-dev.github.io/TaskMan/)**

## ✨ Features

- ➕ Create new tasks
- ✏️ Update existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🎯 Set task priority
- 🏷️ Select task categories
- 📊 Track task progress
- 📋 View tasks in an organized task list
- 📱 Responsive user interface

## 🛠️ Tech Stack

## 📊 Progress Tracking

TaskMan includes a progress tracker that calculates and displays task completion progress based on the tasks in the application.

This gives users a quick overview of how much of their task list has been completed.

## 📝 Task Management

Users can manage their tasks through the task form and task list.

Each task can contain information such as:

- Task title
- Category
- Priority
- Completion status

The task list provides controls for managing and updating tasks.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/mohammed-hamza-dev/TaskMan.git
```

### 2. Navigate to the project

```bash
cd TaskMan
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will start the application locally and provide a local development URL in the terminal.

## 🏗️ Build for Production

Create a production build with:

```bash
npm run build
```
